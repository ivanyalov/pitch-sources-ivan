# Third-party materials

The library contains educational reference material from the linked authors and publishers. Their copyrights, trademarks, and existing notices remain with their respective holders. No blanket license is applied to this repository or to downloaded third-party files.

The catalogue records the source, the actual download location, file type, and whether a PDF is an original published file or a generated reading copy. A publicly accessible file is not, by itself, evidence of an unrestricted redistribution license.

The repository is a public reference collection. Review the recorded rights and publisher terms before reusing or redistributing individual files. A source marked `not_verified` has no verified redistribution permission recorded here; public repository access does not grant such permission.

Mirrors are explicitly identified. Generated reading copies must retain source attribution and must not be described as original author-supplied PDF or PowerPoint files. Sources that require an account, a payment, or an unavailable download are retained as links; no access controls are bypassed.

Third-party files are kept unchanged. Our own outline PDF is identified as a generated document. The source documents and their existing notices take precedence over catalogue notes.
